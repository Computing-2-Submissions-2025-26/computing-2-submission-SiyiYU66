Battleship

Namespace

Battleship

Description:

  • A pure-functional engine for the classic Battleship board game. The board is the single source of truth: a ship's identity and footprint are read directly from the cells (via cell.shipName), so every operation depends only on its arguments — there is no hidden module state to keep in sync.

(static) ghost_slide(board, ship_name, direction, distanceopt) → {Battleship.Board}

Description:

  • Slides the named ship distance tiles in one direction, applying one tile at a time via Battleship.move_ship. The slide is all-or-nothing: if any step is illegal (off the board, blocked by another ship, or the ship is already sunk) the original board is returned unchanged. Callers can detect failure by testing {@code result === board}.
